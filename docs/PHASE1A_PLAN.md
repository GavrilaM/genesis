# Phase 1A — Persistent Individual Identity and Population Ownership

Approved scope: passive identity and exclusive population ownership. Phase 1B
decisions, memories and autonomous actions are excluded.

1. Preserve one combined biological transaction. Persist anonymous cohorts plus
   exclusive living identities; transient combined counts feed the existing food,
   demographic and migration algorithms. Assign sampled outcomes conditionally
   with separate identity randomness, then partition ownership before commit.
2. Add atomic, sequenced promotion and activation-reservation commands, retained
   deceased identities, explicit age provenance and read-only inspection. Default
   budgets: 256 living identities, 64 active reservations; no cognition runs yet.
3. Version snapshots/engine and expose a separate identity event chain, CLI
   commands, canonical biological/resource projections and archive verification.
4. Test conservation, passive equivalence, failed/repeated commands, lifecycle,
   scarcity, full budgets, observation neutrality, migration and exact resume.
5. Run all tests and serial 1,000-year 0/64/256 identity benchmarks, including
   passive and activation-reserved configurations. Publish evidence and precise
   Phase 1B boundaries, commit and verify GitHub push. Stop before Phase 1B.

The Phase 1 proposal is approved subject to the user's refinements. The initial
implementation retains all promoted identities until death, does not fabricate
adult ages or past events, and keeps anonymous reproduction independent of the
identity budget. Future exploration must use local observations and explicit
unknown destination conditions, never omniscient simulation queries.
